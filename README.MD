# What is this chess variant? 
In this chess variant, you won't just be moving your pieces! At the start of the game, players will take turns placing a 2x2 piece of chessboard as well as a chess piece of their own. This will continue until all pieces have been placed, at which point play will proceed as normal, just with an irregular board and piece starting position. 

# End Goal 
We hope for this game to eventually be a stand alone web application where friends can play with each other, similar to Codenames (https://codenames.game/).

# How to run
Run with python -m http.server
